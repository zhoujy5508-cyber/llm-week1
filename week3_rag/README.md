# Week 3 · 矿产能源政策 RAG 知识库与召回归因实验

- **切片实测发现**：`chunk_size=512`（token）、`chunk_overlap=50` 共切出 **89 个 chunk**，每块平均 **370.7 个汉字**（最长 448 字），验证了中文在英文偏重分词器下更费 token。

## 2. 脚本说明
- `build_index.py`：离线加载本地 `BAAI/bge-small-zh-v1.5` 中文向量模型，对 `docs/` 切片并持久化索引至 `storage/`（不调用对话 API）。
- `query_rag.py`：透明拆解版 RAG——先用 `retriever.retrieve()` 单独打印 Top-K 召回原文与相似度，再将原文拼进 `messages` 调用 `deepseek-chat`（`temperature=0`）生成带出处回答。

## 3. 周四三层错误归因实测（`TOP_K=3`）
| 题号 | 问题类型 | 实跑结果 | 错误归因（检索 vs 生成） | 对应改进方向 |
| :--- | :--- | :--- | :--- | :--- |
| 题 A | 换词语义题（“强制配储”→136号文前置条件） | 漏答（回答未提及） | **检索层没召回**：同义换词发生语义漂移，136 号文被挤出 Top-3 | 加大 `TOP_K` / 混合检索（BM25+向量）/ Rerank |
| 题 B | 跨文件复合题（光伏上网 + 绿证核发） | 上网满分，绿证漏答 | **检索层单文档霸榜**：Top-3 全被光伏管理办法占满，绿证文件未进前 3 | 问题拆解（Query Decomposition）或知识图谱 |
| 题 C | 长文首尾分离题（战略矿产支持 + 施行日期） | 支持政策满分，施行日漏答 | **检索层弱尾部被吞**：正文强关键词吸走全部槽位，文末第八十条短句落榜 | 元数据入库（`corpus_meta.csv`）与结构化过滤 |

**核心结论**：3 道测试题中，Prompt 防幻觉约束 100% 生效（未召回时均诚实声明“未提及”，无编造）；全部失误均源于检索召回环节，验证了 RAG 调优的铁律——**先修检索，再调生成**。
